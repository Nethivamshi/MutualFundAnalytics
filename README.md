Mutual Fund Analytics Capstone Project
Project Overview
This project analyzes mutual fund industry data using Python, SQLite, SQL, and Tableau. The objective is to transform raw mutual fund datasets into meaningful insights through ETL, Exploratory Data Analysis (EDA), Performance Analytics, Advanced Analytics, and Interactive Dashboards.
Project Objectives
Build an end-to-end Mutual Fund Analytics pipeline.
Perform data cleaning and preprocessing.
Analyze fund performance and investor behavior.
Calculate risk and return metrics.
Create Tableau dashboards for visualization.
Generate actionable insights and recommendations.
